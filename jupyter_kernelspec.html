jupyter_kernelspec

load("@rules_jupyter//jupyter:jupyter_kernelspec.bzl", "jupyter_kernelspec")

jupyter_kernelspec(name, data, args_template, argv, display_name, env, interrupt_mode, kernel_name,
                   language, path_tools, transport)

Defines a Jupyter kernel that notebooks can be executed with.

The rule is language agnostic. It describes how to launch a kernel process in the same way a kernel.json file does, but with files tracked by Bazel. Kernels are attached to a jupyter_toolchain via its kernels attribute and selected by notebooks using jupyter_notebook.kernel (or jupyter_toolchain.kernel for a default).

File references in argv and env use $(rlocationpath ...) expansion over the targets in data. The rules resolve them to real paths wherever the notebook is executed (build actions, tests, bazel run and Jupyter Lab). Jupyter's own {connection_file} placeholder and ${VAR} environment substitution continue to work.

Example:

jupyter_kernelspec(
    name = "julia",
    display_name = "Julia",
    language = "julia",
    argv = [
        "$(rlocationpath :ijulia_kernel)",
        "{connection_file}",
    ],
    data = [":ijulia_kernel"],
    # A file containing `empty!(ARGS); append!(ARGS, {args})`.
    args_template = "args_template.jl",
)

jupyter_toolchain(
    name = "jupyter_toolchain",
    kernels = [":julia"],
    ...
)

jupyter_notebook(
    name = "notebook",
    src = "notebook.jl",
    kernel = "julia",
)

ATTRIBUTES

NameDescriptionTypeMandatoryDefault
nameA unique name for this target.Namerequired
dataFiles and executables required by the kernel at runtime. These are the targets available for $(rlocationpath ...) expansion.List of labelsoptional[]
args_templateA file holding a code cell template used to forward args of jupyter_notebook_test, jupyter_notebook_binary, jupyter_report and jupyter_lab to the notebook. The cell is prepended to the notebook before execution. The only placeholder is {args}, replaced by a JSON array of the arguments (e.g. a file containing empty!(ARGS); append!(ARGS, {args}) for Julia); other braces are left as they are. When unset, notebooks using this kernel cannot be given args.LabeloptionalNone
argvThe command used to launch the kernel. Supports $(rlocationpath ...) expansion for targets in data and path_tools as well as Jupyter's {connection_file} placeholder.List of stringsrequired
display_nameThe human readable name of the kernel. Defaults to kernel_name.Stringoptional""
envEnvironment variables for the kernel process. Values support $(rlocationpath ...) expansion and Jupyter's ${VAR} substitution with the environment of the process launching the kernel.Dictionary: String -> Stringoptional{}
interrupt_modeHow the kernel is interrupted. signal sends SIGINT, message sends an interrupt_request. Defaults to Jupyter's default (signal).Stringoptional""
kernel_nameThe name of the kernel as referenced by jupyter_notebook.kernel and notebook metadata. Defaults to the target name.Stringoptional""
languageThe language of the kernel (e.g. python, julia, rust). Recorded in notebook metadata and used by exporters for syntax highlighting.Stringrequired
path_toolsExecutables whose parent directories are prepended to PATH for the kernel process. Useful for kernels that shell out to compilers or interpreters. Each target must provide exactly one file.List of labelsoptional[]
transportThe ZeroMQ transport used to talk to the kernel. Defaults to ipc on Unix, which avoids port collisions between notebooks Bazel runs in parallel, and tcp on Windows. Kernels whose ZeroMQ lacks IPC support (e.g. prebuilt evcxr_jupyter binaries) must set tcp.Stringoptional""

JupyterKernelspecInfo

load("@rules_jupyter//jupyter:jupyter_kernelspec.bzl", "JupyterKernelspecInfo")

JupyterKernelspecInfo(args_template, argv, display_name, env, files, interrupt_mode, kernel_name,
                      language, path_tools, rlocations, runfiles, spec, tools, transport)

Provider describing a Jupyter kernel that notebooks can be executed with.

FIELDS

NameDescription
args_templateFile: A code cell template used to forward notebook args to the kernel, or None when the kernel does not support args.
argvList[str]: The kernel launch command. File references are rlocationpaths which are resolved at runtime.
display_namestr: The human readable kernel name.
envDict[str, str]: Environment variables set for the kernel process.
filesDepset[File]: All files required by the kernel at runtime.
interrupt_modestr: The Jupyter interrupt mode (signal or message) or an empty string for the Jupyter default.
kernel_namestr: The kernel name used by jupyter_notebook.kernel and notebook metadata.
languagestr: The language of the kernel (e.g. python, julia, rust).
path_toolsList[str]: rlocationpaths of the path_tools executables. The directory of each resolved file is prepended to PATH for the kernel process.
rlocationsDict[str, File]: Every file referenced by argv, env or path_tools, keyed by rlocationpath.
runfilesrunfiles: The runfiles of the kernel.
specFile: A json file describing the kernelspec, consumed by the rules_jupyter process wrappers.
toolsList[FilesToRunProvider]: Executables used by the kernel. Passed as tools to build actions so their runfiles are available.
transportstr: The ZeroMQ transport (ipc or tcp) used to talk to the kernel, or an empty string for the platform default.
